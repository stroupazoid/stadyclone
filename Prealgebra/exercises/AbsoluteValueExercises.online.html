Absolute Value or Opposite?

Which statement is true?
\(|-6|=-6\) \(|-6|=6\) \(-|-6|=6\)
Which statement is true?
The absolute value of \(-7\) is \(7\). The opposite of \(-7\) is \(-7\). The absolute value of \(7\) is \(-7\).

Reading Expressions from the Inside Out

A computer evaluates the expression below from the inside outward.
\[ -(-5) \]

First identify the number being acted on: \(-5\).

The outside negative sign means “take the opposite.”

\[ -(-5)=\answer {5} \]
Evaluate the expression from the inside outward.
\[ -|-4| \]

First evaluate the absolute value:

\[ |-4|=\answer {4} \]

Now take the opposite:

\[ -(4)=\answer {-4} \]
Evaluate the expression from the inside outward.
\[ -|-(-3)| \]

First evaluate the innermost operation:

\[ -(-3)=\answer {3} \]

Next take the absolute value:

\[ |3|=\answer {3} \]

Finally take the opposite:

\[ -(3)=\answer {-3} \]

Error Analysis

A student writes
\[ -|-8|=8. \]

What mistake did the student make?

The student evaluated the absolute value incorrectly. The student forgot that the negative sign outside the absolute value means to take the opposite after finding the absolute value. The student should have changed \(-8\) to \(-16\).

Now evaluate the expression correctly.

\[ -|-8|=\answer {-8} \]

Application

A machine is supposed to cut a metal rod to exactly \(25\) centimeters. A rod is cut to \(24.6\) centimeters.

The error is

\[ 24.6-25=\answer {-0.4}. \]

The absolute error is

\[ |24.6-25|=\answer {0.4}. \]

Which statement best describes the result?

The rod is \(0.4\) centimeters too long. The rod is \(0.4\) centimeters too short. The rod is exactly the correct length.
