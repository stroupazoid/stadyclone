Summary

  1. Adding Numbers with the Same Signs

    1. Add their absolute values.
    2. Write the answer with the common sign.

  2. Adding Numbers with Different Signs

    1. Find the absolute value of each number.
    2. Subtract the smaller absolute value from the larger absolute value.
    3. Write the answer using the sign of the number with the larger absolute value.

    Don’t Forget!

    These two rules came from thinking in terms of assets and debts, so you can always find an answer that way.
